# ⛏️ 深渊矿工（Abyss Miner）

> 一款温暖又致命的地底钻探游戏：观察征兆、判断风险、赌一把往下钻，把稀有矿石和深渊晶体带回地面。

> 📸 **截图占位**：运行 `npm run dev` 后见主菜单（本文档发布前可替换为真实截图）。

## ✨ 功能特性

核心循环：**看征兆 → 判断 → 选模式 → 钻进 → 结算 → 撤退或继续 → 入库 → 升级 → 向更深进发**。

## 🚀 快速开始

**要求**：Node.js ≥ 22.5（项目使用 `node:sqlite` 本地数据库，需要新版 Node，建议 22.5+）。

```bash
npm install
npm run dev
```

然后打开 **http://localhost:3000** 即可游玩。

生产构建：

```bash
npm run build
npm start
```

## 🏆 排行榜架构说明

- 默认使用本地 SQLite 数据库 **`data/game.db`**（Node 内置 `node:sqlite`，零第三方依赖）。
- 适合**单机游玩或本地局域网共享**：让同一网络内的玩家都访问跑游戏的这台机器，即可共享排行榜。
- ⚠️ **公网部署时需要换成外部数据库**（如 PostgreSQL、SQLite 云盘 / 托管服务等）——`node:sqlite` 是文件存储，不适合多实例部署。
- 账号体系：用户名 + 密码，密码以 **scrypt 哈希**存储；登录后写入 **7 天 httpOnly cookie** 会话。未登录可正常游玩，但无法上榜。

## 📜 游戏规则简述

- **每层流程**：观察征兆 → 判断风险 → 选择钻进模式 → 钻进 → 结算 → 撤退或继续 → 入库 → 升级。
- **钻进模式**：稳妥 ×0.75 ／ 标准 ×1.00 ／ 超载 ×1.70+（超载下稀有矿权重更高）。
- **穿透机制**：一次钻进有较低概率一次钻穿多层，超载概率最高；上限 10 层、概率逐层递减、每层单独结算。
- **危险**：毒气、高温、地底生物、深渊异常（含 6 种异常效果），部分异常会封锁撤退。
- **升级**：5 类永久升级 × 12 级：钻机 / 安全装备 / 背包 / 探测设备 / 支撑装备。
- **检查点**：深度 100 / 300 / 600 / 1000m。

## 🕹️ 操作说明

- 全程 **鼠标点击** 操作。
- **探测器 / 支撑架**：在钻进前使用，用来探明风险、稳住钻机。
- **撤退**：任意时刻都可以撤退返回地面（部分异常效果会封锁撤退）。

## 📁 项目结构与技术说明

```
src/
├── app/          # 页面与 API 路由（Next.js App Router）
├── components/   # 界面组件（主菜单 / 下矿 / 升级 / 排行榜 / 登录）
├── game/         # 游戏引擎（engine / config / world / audio）
└── lib/          # 通用逻辑（api / auth / db）
```

技术栈：**Next.js 15（App Router）＋ React 19 ＋ TypeScript**，Canvas 2D 手绘画面，WebAudio 全合成音效，`node:sqlite` 本地数据库。除 Next.js / React 自身外，**零第三方运行时依赖**。
