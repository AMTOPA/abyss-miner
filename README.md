# ⛏️ 深渊矿工（Abyss Miner）

> 一款温暖又致命的地底钻探搜打撤游戏：在大厅整备补给，携带现金与装备深入地下，在灾难降临前带着矿石撤离、入库、变现，向更深层进发。

## ✨ 功能特性

核心循环：**大厅整备 → 下矿钻进 → 黑市补给/变现 → 撤离入库 → 仓库变现 → 升级装备 → 再入深渊**。

| 类别 | 内容 |
| --- | --- |
| 🏛️ 大厅 | 地铁逃生/三角洲行动式七页签：**出矿 / 仓库 / 商店 / 装备 / 图鉴 / 排行榜 / 设置** |
| 🪙 双现金 | **仓库现金**（局外货币）与**随身现金**（开局自选携带，局内黑市/维修/强盗使用，剩余带回） |

| 🎒 格子背包 | 同种矿石×同品质最多 99/格，特殊物品 1/格；初始 5 格，升级背包每级 +1 格 |
| 🏦 仓库 | 撤离的矿石**不直接变现**，存入仓库；随时可按全价出售换成现金 |
| 🛒 每日商店 | 消耗品 + 装备，**每日刷新**，可能刷出「极品」装备；现金对每件物品作用一致 |
| 🎒 装备栏 | 钻头 / 背包 / 护甲 / 探测镜 / 护符 五槽位；v4 起装备自带 **规则型特性**（冰芯散热/磁力压缩/双倍收获等 16 种） |
| 🚪 黑市 | 检查点层（100/300/600/1000m）必出 + 随机层 15%：折价卖矿换现金、货架双支付（矿石或现金）、维修、**每日任务刷好感度**、**订单系统** |
| 🧪 一次性增益 | 出发前用现金购买或**随机抽取**：黑市折扣 / 高品质概率 / 穿透增幅 / 减损耗 / 护盾 / 防毒等 |
| 🎯 难度模式 | **温和**（无损耗 ×0.8）／ **中等**（默认，损耗衰减）／ **硬核**（损耗 + 随机强盗 ×1.5），难度越高收益越高 |
| 🔧 设备损耗 | 耐久每掉 25% 性能 -10%；可在黑市维修 40% 或回地面大修 |

| 🕳️ 钻进模式 | 稳妥 ×0.55（可中途收手）/ 标准 ×1.00 / 超载 ×1.65+（热量累积、可释放热量获得爆发收益、满 100 过载停机） |
| 🔥 Combo | 连续高效作业累积连击，收益加成上限 ×5 |
| 🌀 穿透机制 | 一次钻进有概率一次钻穿多层（上限 10 层、概率逐层递减、每层单独结算） |
| 💎 道具掉落 | 约 8%/层掉落消耗品（维修套件 / 应急燃料 / 护盾 / 净化剂 / 炸药 / 高级维修套件 / 应急锚点），占背包格 |
| 🧬 富矿脉 | 可榨取 4 次，收益递增但风险也随之递增 |

### 🏆 v4：排行榜多榜

- **价值榜**（单次最高入库价值）／ **深度榜**（最深抵达）／ **硬核榜**（仅硬核，按价值）／ **净收益榜**（入库价值 - 出发花费），四榜切换。
- 注册登录后成绩自动上榜，同一局幂等（不会重复上榜），每小时限 20 次提交。

### 🆕 v5：灾难平衡与应急锚点

| 类别 | 内容 |
| --- | --- |
| ⚖️ 灾难率减半 | 灾难基础概率 10% → 3%，深层塌方基数 0.30 → 0.22，安全装备每级削减 5% 塌方风险（原 3%）：**正常路径灾难率整体约减半**（300m 普通 ≈13%，原 ≈31%；超载 ≈26%，原 ≈52%） |
| 🗻 深渊保底威胁 | 深渊深处存在最低灾难威胁（0.02 + 深度/1000×0.05），**满配也无法完全规避**：1000m 满配单局灾难率约 **30%**（原 ≈87%），硬核/超载收益仍与风险正相关 |
| ⚓ 应急锚点 | 新消耗品：使用后接下来 **50m（5 层）内灾难事故降级为严重事故**（不再整局失败，仅损失 30% 矿石并退回一层），商店 / 黑市 / 掉落均可获取，适合深潜保命 |

## 🚀 快速开始

**要求**：Node.js ≥ 22.5（项目使用 `node:sqlite` 本地数据库，需要新版 Node，建议 22.5+）。

```bash
npm install
npm run dev
```

然后打开 **http://localhost:3000** 即可游玩。

生产构建：

```bash
npm run build
npm start
```

## 🏆 排行榜架构说明

- 默认使用本地 SQLite 数据库 **`data/game.db`**（Node 内置 `node:sqlite`，零第三方依赖），可用环境变量 `ABYSS_DB_PATH` 覆盖数据库路径。
- 适合**单机游玩或本地局域网共享**：让同一网络内的玩家都访问跑游戏的这台机器，即可共享排行榜。
- ⚠️ **公网部署时需要换成外部数据库**（如 PostgreSQL、托管 SQLite 等）——`node:sqlite` 是文件存储，不适合多实例部署。
- 账号体系：用户名 + 密码，密码以 **scrypt 哈希**存储；登录后写入 **7 天 httpOnly cookie** 会话。未登录可正常游玩，但无法上榜。

## 📜 游戏规则简述

- **每层流程**：观察征兆 → 判断风险 → 选择钻进模式 → 钻进 → 结算 → （黑市/继续/撤退）。
- **事件优先级**：检查点营地 > 区域 Boss（500/950m）> 模块补给站（每 100m+50）> 路线分岔（每 30m）> 特殊房间（6%+）> 正常下降。
- **随身现金**：出发前在大厅「出矿」页自选携带数量（滑杆 / +/- / 输入框 / 快捷金额）；局内黑市交易、维修、强盗勒索均使用随身现金；撤离后剩余现金自动回到仓库。
- **撤离结算**：背包矿石全部存入仓库（不直接变现），随身现金回归仓库，按评级发放额外现金，并记录排行榜成绩。
- **黑市**：出售矿石 = 正常价 55%（好感度每级 +5%，上限 75%）；货架商品支持「x 个指定矿石」或「现金」双支付，二者等价；好感度只通过每日任务与订单提升。
- **损耗**：中等/硬核模式下耐久每损失 25% 性能 -10%；黑市维修恢复 40%，回地面后可花现金大修 100%。
- **难度收益**：温和 ×0.8（无损耗）/ 中等 ×1.0 / 硬核 ×1.5（含强盗事件，约 12% 层概率）。

## 🕹️ 操作说明

- 全程 **鼠标点击** 操作。
- **探测器 / 支撑架**：在钻进前使用，用来探明风险、稳住钻机。
- **撤退**：任意时刻都可以撤退返回地面（部分异常效果会封锁撤退）。
- **跳过钻进动画**：钻进中可点击「跳过 ⏭」直接结算。
- **背包管理**：结算/观察面板可丢弃矿石、使用道具，满格时多出的矿石会散落损失。
- **超载收手 / 释放**：标准/稳妥钻进可中途收手按进度结算；超载模式可释放热量获得爆发收益（热量越高收益越高）。

## 📁 项目结构与技术说明

```
src/
├── app/          # 页面与 API 路由（Next.js App Router）
├── components/   # 大厅（出矿/仓库/商店/装备/图鉴/排行榜）、局内 UI、v4 事件面板、黑市、登录
├── game/         # 游戏引擎（engine / world / content / config / items / save / types / audio）
└── lib/          # 通用逻辑（api / auth / db）
```

技术栈：**Next.js 15（App Router）＋ React 19 ＋ TypeScript**，Canvas 2D 手绘画面，WebAudio 全合成音效，`node:sqlite` 本地数据库。除 Next.js / React 自身外，**零第三方运行时依赖**。
